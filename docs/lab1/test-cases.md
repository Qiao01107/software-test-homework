# Calculator.add 测试用例清单

依据需求：两个整数都大于 0 时返回两者之和；任一整数小于或等于 0 时返回 0。预期值在执行前按此规则确定。每行由 JUnit 5 参数化测试独立执行一次。所有正数求和用例均不涉及 `int` 溢出。

| 编号 | 场景 | num1 | num2 | 预期输出 | 实际输出 | 结果 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| P01 | 两个最小正整数 | 1 | 1 | 2 | 2 | 通过 |
| P02 | 两个不同正整数 | 2 | 3 | 5 | 5 | 通过 |
| P03 | 交换正整数顺序 | 3 | 2 | 5 | 5 | 通过 |
| P04 | 较大正整数之和 | 1000000000 | 1000000000 | 2000000000 | 2000000000 | 通过 |
| Z01 | 第一个数为 0，第二个数为正 | 0 | 1 | 0 | 1 | 失败 |
| Z02 | 第一个数为正，第二个数为 0 | 1 | 0 | 0 | 0 | 通过 |
| Z03 | 两个数都为 0 | 0 | 0 | 0 | 0 | 通过 |
| N01 | 第一个数为负，第二个数为正 | -1 | 1 | 0 | 0 | 通过 |
| N02 | 第一个数为正，第二个数为负 | 1 | -1 | 0 | 0 | 通过 |
| N03 | 负数与 0 | -1 | 0 | 0 | 0 | 通过 |
| N04 | 0 与负数 | 0 | -1 | 0 | 0 | 通过 |
| N05 | 两个数都为负 | -1 | -1 | 0 | 0 | 通过 |

通过用例的实际值由相应 `assertEquals` 成功确认；Z01 的实际值由 Surefire 断言失败记录确认。
